# Description
In this team project, we were tasked with applying Multiple Regression to a large data set of single-family homes in Saratoga, NY with a goal of determining a model that can be used to predict the value of a home in that area.

# Methods
Data Cleaning, Data Transformation, EDA and Modeling was completed in JMP.

# Process
1) Transform skewed data, and convert to dummy variables where applicable.
2) Generate visualizations of finalized variables.
3) Develop candidate models.
4) Compare candidate models based on accuracy and simplicity.
5) Prove final model meets the required assumptions.
6) Consolidate findings and visuals in a Technical Report.
